Screen Dimmer by Shardapps - Windows 11 developer preview

RECOMMENDED: Run Screen-Setup-1.1.0-x64.exe on an Intel/AMD PC, or the
arm64 setup on a Windows on Arm PC. Setup installs for your current user,
creates a Start menu shortcut, and adds an entry under Settings > Apps.
No administrator rights or certificate imports are required.

PORTABLE: Extract Screen-portable-x64.zip (or arm64.zip) completely, then
run Screen.exe from the extracted folder. This does not install the app.

These are unsigned developer previews. Windows may show an unknown
publisher or SmartScreen warning. Organizational application-control
policies may block unsigned software; the Microsoft Store release is available at
https://apps.microsoft.com/detail/9PNHDHKMHDLG (Store updates arrive separately).

Screen starts paused by default. Settings offers opt-in saved-dimming resume. Move the slider to enable dimming. Alt+S opens or
hides the compact panel above the bottom-right taskbar (Ctrl+Alt+S is the
fallback if Alt+S is reserved). Click outside or press Escape to dismiss.
Right-click the tray icon for pause, display/tint settings, Restore and Quit.
Emergency restore: Ctrl + Alt + Shift + F12.

Unsigned .msix files are separate packaging-validation artifacts, NOT
normal double-click installers. They are intended for Store packaging
development and need an appropriate trusted signature for normal install.

Source, documentation and issue reports: https://github.com/shardapps/screen

Use the flyout settings icon for screen selection, six themes plus System,
brightness presets, timed pause, shortcut/step choices, and opt-in Windows startup.
Settings > Desktops enables different brightness for Windows Task View desktops.
To resume saved dimming at sign-in, enable both Start with Windows and
Apply saved brightness when Screen opens in Preferences.
